# MoscowHack: Автоматизация приёма и выдачи инструментов

## Описание
Сервис позволяет по фотографии автоматически распознавать набор инструментов и сверять их с эталонным списком. Решение состоит из:
- Frontend (HTML/CSS/JS)
- Backend (FastAPI, работа с данными и API)
- CV-сервис (YOLOv8 для распознавания изображений)

Более подробное описание можно найти в папке **docs** со всеми документами и презентацией

## Быстрый старт
```bash
git clone https://github.com/KaktusYozhika/MoscowHack
cd MoscowHack
docker compose up --build
```
После этого перейдите в браузере по ссылке **http://localhost:3000/**

## Тестирование модели на нескольких изображениях
```bash
git clone https://github.com/KaktusYozhika/MoscowHack
cd MoscowHack
python cv\process_batch --input "your_dataset_path" --out "your_output_path"
```
Также можно задать параметры: **--conf**(уверенность модели), **--iou**(допускаемый процент пересечения боксов)
После прогона файла по указанному пути **--out** сформируются json файл с разметкой и папка с размеченными картинками
